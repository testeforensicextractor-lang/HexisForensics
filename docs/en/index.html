What it does

Routine logical acquisition of what answers the examination — recording how each piece of data was obtained and delivering documents that stand on their own.

📱

Android

Address book, calls, SMS/MMS, media, WhatsApp (via the backup with a 64-digit key), system artifacts and diagnostics — with no elevated privilege.

🍎

iPhone

Local backup, common or encrypted, with decryption: messages, address book, calls, WhatsApp and photos.

💽

USB drives and disks

Copy of the user's folders, index of the drive with SHA-256 and a volume image, with a write blocker.

🔒

Hash sealing

The SHA-256 of each file is computed at the moment of acquisition; integrity can be checked at any time.

📄

Documents

Extraction Report, Content Report, PDF of selected conversations and the Expert Report, signed by the examiner.

🛡️

Examination without extraction

The report of the locked or damaged device, with the same chain of custody.

Not collected is not does-not-exist

The principle that guides every screen and every document: the tool never asserts what it did not verify.

  • Never assert what was not verified. When a piece of data is not obtained, the document says why — and its absence in the material is never presented as its absence on the device.
  • Every change to the device is recorded and justified. The modules that touch the device start unchecked and leave a record of what was done.
  • What is necessary, well recorded. Collect what matters to the examination and document the provenance of each piece of data: which file it came from, by which route, with which hash.

Get started

Download the installer for Windows. If your computer blocks unsigned installers, the tool also runs directly from source.

Installer (recommended)

Download the installer on the releases page.

Verify the published SHA-256 hash with Get-FileHash.

Run it and register your examiner profile.

🔒 Verify the integrity

In PowerShell, inside the downloaded file's folder:

Get-FileHash .\HexisForensics-Setup-1.0.0.exe

The result must be identical to this (v1.0.0):

de4abda974d2a0267df98ba461fefb4e4eadd8f0cf52950c9c2ce7ba5723c5bf

If a single character differs, do not run the file. The same value is in the .sha256 next to the installer.
